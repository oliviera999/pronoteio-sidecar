# Lot L01 — Sidecar : décodeurs et lecture de classe en série

Vague 1, session séparée. Dépôt `pronoteio-sidecar`, branche de départ `suivi/integration`, branche du lot
`suivi/L01-sidecar`. Ce fichier existe à l'identique dans les deux dépôts (`docs/olutionsuivi/lots/L01.md`).

## But

Donner au collecteur de Moodle ce qui lui manque : les absences et retards datés de toutes les matières, le détail
des plans d'accompagnement, les résultats des années précédentes, et une lecture groupée d'une classe entière en une
demande, cadencée, reprenable, à résultat partiel exploitable. Lecture seule, jamais de vrai Pronote.

## À lire, et rien d'autre

- `src/teacher/classlife.ts` autour de `officialFromRecap` et `decodeRecap` (modèle de décodeur), son test
  `test/classlife.test.ts` et `test/fake-session.ts` (simulation de Pawnote).
- `src/jobs.ts` (modèle de tâche : `app.inject`, reprise de `/students/files`).
- Si le dépôt `mood_prod` est attaché à la session : `docs/pronoteio/vue-pp.md`, sections 7 et 8 seulement, et
  `docs/olutionsuivi/formes/` s'il existe (formes réelles relevées par Oliv). Sinon, les faits utiles sont ci-dessous.

Pour le reste, grep ciblé ou sous-agent d'exploration. Ne lis pas `src/normalise.ts` ni `dist/` en entier.

## Tests exigés (`npm run typecheck`, `npm test`, `npm run build && git diff --exit-code -- dist`)

- Chaque décodeur : forme reconnue, forme inconnue (`format_unknown` + `shape` sans aucune valeur), fonction refusée
  par le profil (`access_denied`, pas d'autre appel).
- Lecture groupée d'une classe de 31 élèves, tous les blocs.
- `rate_limited` simulé au milieu d'un bloc, puis reprise : rien de perdu, rien lu deux fois.
- Session web fermée en cours de série : `waiting`, `session.web: "reopen_required"`, puis reprise.
- Une fonction en échec : son bloc `failed` ou `unavailable`, les autres `done`, résultat lisible.
- Seconde demande pendant une lecture : `409 collect_running`.
- Aucune donnée de santé dans le journal ni le cache.
- `contracts.test.ts` au vert avec les schémas des nouvelles routes.

Fixtures : noms fictifs, valeurs générées, jamais lues sur un vrai serveur.
